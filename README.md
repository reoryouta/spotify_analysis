- Анализ музыкальных предпочтений на Spotify

- О проекте
Аналитическое исследование факторов, влияющих на популярность музыкальных треков на платформе Spotify. Проект демонстрирует навыки работы с данными, SQL-анализ и визуализацию.

- Ключевые выводы
 Треки с матом в среднем на 1.68 пункта популярнее
 Комбинация низкой танцевальности и высокой энергии дает максимальный результат
 Самые популярные треки имеют рейтинг 80+ баллов

- Технологии
 MySQL - анализ данных
 Excel/Libreoffice - визуализация
 SQL запросы - агрегация данных
